# SFTP Xavi support

Report bugs and request features in [luckyshot/vscode-sftp-xavi/issues](https://github.com/luckyshot/vscode-sftp-xavi/issues). This independent fork is supported in this repository; upstream maintainers are not responsible for its behavior.

Include your SFTP Xavi version, Visual Studio Code version, operating system, protocol, reproducible steps, and expected versus actual behavior. Set `sftpXavi.debug` to `true`, reload the editor, and check **View → Output → SFTP Xavi** for logs.

Remove passwords, private keys, passphrases, tokens, and other private details from logs and configuration examples before sharing them. Keep an unredacted copy locally if you need it for your own investigation.

Existing `.vscode/sftp.json` files remain compatible. See the [migration guide](README.md#moving-from-the-original-extension), [configuration guide](docs/configuration.md), and [FAQ](FAQ.md).
